## K. 서버 및 GPU 환경 개발 요구사항

### K1. 우선 개발 환경

| 항목 | 계획 환경 |
|---|---|
| GPU 서버 | Vast.ai |
| GPU | NVIDIA GeForce RTX 5090 |
| VRAM | 32GB |
| LLM | Qwen3.8-27B |
| 양자화 | NVFP4 (4비트) |
| vLLM 모델 | `Inferact/Qwen3.8-27B-NVFP4` |
| SGLang 모델 | `nvidia/Qwen3.8-27B-NVFP4` |
| 모델 서버 | OpenAI 호환 API |
| 모델 식별자 | `qwen` |
| 서버 포트 | `8000` |
| 최대 컨텍스트 | 32,768토큰 |

위 환경을 우선 기준으로 개발하되, 실제 실행 결과와 호환성, 성능 검증에 따라 개선할 수 있도록 설계한다.

### K2. 기존 실행 파일 활용

기존 `setup.sh`, `serve.sh` 및 관련 서버 코드를 우선 분석·활용한다. 기존 모델 로딩 방식·실행 옵션 확인, vLLM 우선 검토, SGLang 경로 유지·비교, NVFP4 우선 적용 후 실제 환경 호환성·정상 동작 검증, 문제 시 원인 분석·해결책 제시.

```bash
ENGINE=vllm QUANT=nvfp4 bash serve.sh
```

```bash
ENGINE=sglang QUANT=nvfp4 bash serve.sh
```

- Vast.ai RTX 5090에서 우선 계획 모델 실행, 에이전트는 OpenAI 호환 API로 추론 요청.
- Action API 호출과 정책 판단은 에이전트 애플리케이션이 관리.
- 모델 서버 주소·API 키·액션 토큰 등은 환경변수.
- 서버 연결·재연결·오류 처리·자동 재시작·로그 기록 구현.
