# 교동마을 산지직송 — AI TOP 100 2026 예선 개발 요구사항 전체 패키지

## 작성 목적

사용자가 요구한 **대회 관련 모든 제공 자료와 설명을 가능한 한 누락 없이 개발 요청에 전달**하도록 만든 패키지다. 원문 파일 **71개**(변경하지 않은 바이너리 사본), 검색 가능한 텍스트 추출본, OpenAPI 41개 전 항목, 구두 인터뷰의 사실/모름/중복 기록, 설계 요구 프롬프트 및 자체 회귀 테스트 107개를 포함한다.

## 가장 먼저 읽을 파일

1. **`DEVELOPMENT_MASTER_PROMPT.md`** — 개발자/코딩 에이전트에게 그대로 입력할 지시문. 부속 파일 필수 참조.
2. **`DEVELOPMENT_MASTER_PROMPT_ALL_IN_ONE.md`** — 위 지시문 + 인터뷰/예외/테스트/API 전 항목 + 추출 가능한 제공 자료 전문 + `actions.json` 원문을 붙여놓은 큰 단일 프롬프트. **이미지·사진 원본은 이 파일 하나로 표현할 수 없으므로 반드시 ZIP의 원본 파일을 함께 제공.**
3. `API_FULL_REFERENCE.md` — 41개 OpenAPI (GET 23 + 접수 POST 17 + 연습 초기화 POST 1), 각 요청/응답 schema.
4. `KNOWLEDGE_AND_EDGE_CASES.md` — 충돌·시행일·해석 우선순위·정합성 예외.
5. `INTERVIEW_HISTORY_AND_GAPS.md` — 사람별 담당업무/확인 실패, 구두 정보/문서 수집 이력.
6. `TEST_MATRIX.md` — 107개 자체 회귀 사례 및 API 전개 검증.
7. `metadata/api_registry.json` / `metadata/api_schemas.json` / `metadata/test_scenarios.json` / `metadata/manifest.json` — 기계 가독 자료 및 SHA-256.
8. `source_text/` — PDF/DOCX/HTML/XLSX 및 스크립트 추출 원문. 각 파일 이름 끝에 `.txt`를 붙였다.
9. `original_sources/` — 원본 전체 71개. PDF/엑셀/HTML/DOCX/PNG/서버 코드·기타 원본 포함.

## 실행 순서

- 개발 AI가 폴더 전체 파일에 접근 가능하면 `DEVELOPMENT_MASTER_PROMPT.md`를 먼저 전달하고 **`original_sources/` 전부와 `source_text/`, API 완전명세를 읽은 뒤** 구현하라고 지시.
- 단일 텍스트만 넣을 수 있으면 `DEVELOPMENT_MASTER_PROMPT_ALL_IN_ONE.md`를 전달하되, 이 파일에 없는 이미지·스캔 원본은 따로 첨부/시각 검사해야 함.
- 원문 일치 검증은 `metadata/manifest.json`의 SHA-256 활용.
- **대회 운영상 심사 시작 2026-10-31 16:00 이후 시나리오/프롬프트/배포 수정 금지**. API 연습 데이터 초기화는 심사 시작/최종 제출 후 금지.

## 원본 보존·한계

- 스캔 PDF 1종은 자동 텍스트가 사실상 비어 있다. 대신 원본 PDF를 포함했다. PNG 사진/스크린샷도 시각 자료로 원본 보존.
- 스프레드시트는 `artifact_tool`로 각 시트의 값을 텍스트로 추출했다. **값뿐 아니라 셀 메타·서식·이미지 검증이 필요하면 원본 XLSX를 열어 확인**.
- HTML 화면 원문은 스크립트 제거 후 텍스트 추출하여 원본 HTML과 함께 포함.
- 이전 대화에서 일어났으나 제공 파일에 없는 **모든 발언의 문자 단위 채팅 로그**, 공개 TC별 모범답안, 실제 액션 토큰, 프로모션 마스터 전체, 일부 가격·라벨 정책 등은 임의 생성하지 않았다. 인터뷰 구두 정보는 확인 가능한 대화 요약으로 보존했다. 이 제약 때문에 “전체 기록의 문자 단위 완전 복제”까지 약속할 수는 없지만, **현재 접근 가능한 원본 파일과 설계·규정·API 관련 사실은 최대한 모두 포함**했다.
- 업로드된 `kakao_bot.py`, `bench.py`, `run_all.py` 등은 기존 준비 코드이므로 새 개발의 참고자료이지 정식 대회 실행 규격의 검증 완료판이 아님.
- 고객에게 내부 규정·비공개 문서 원문을 제공하면 안 됨. 개발 패키지의 내부 문서 포함은 에이전트 개발/판단용이다.
