# 대회 비공개 TC 대비 정책·API 회귀 테스트 매트릭스

아래는 대회 공식 TC가 **아닌 자체 설계 회귀 사례**다. 정확한 정답 문구·실제 API body·접수 결과는 사전 fixture 또는 공개 TC의 실제 데이터와 대조해야 한다.

- 모든 사례는 입력/인증 상태/TC ID/필요 조회/금지 액션/정책 근거/응답 텍스트/지연·API 호출 수를 확장 가능한 구조로 관리한다.
- 목록의 정답 칸은 핵심 판정 가이드이며, 실제 주문 및 API 최신 상태와 달라질 때 원문·API 우선.
